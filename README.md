# IDEA GYM - アイデア発想トレーニングアプリ
**QuintBridge ハッカソンアイデア #9 / 仕様書完全準拠**

> 「地域の困りごとが、ひらめきに変わる。AIと鍛える、アイデア発想トレーニング」

AI開発によってモノづくりのハードルは下がったが、「何を作るか」が浮かばないというボトルネックを解決するため、日常の小さな違和感を仲間とAIでアイデアに変えるトレーニングWebアプリケーションです。

---

## 🚀 起動方法

### 方法1: 開発サーバーで起動（推奨）
ターミナルで本ディレクトリを開き、以下を実行します：
```bash
npm run dev
```
自動的にブラウザで `http://localhost:3000` が開き、アプリが利用可能になります。

### 方法2: ビルド成果物のプレビュー
```bash
npm run preview
```
または `dist/index.html` を利用した静的ホスティング。

## 💡 主要機能（3つのステップ）

1. **ステップ1：気づきのシェア**
   - 通勤時や社内、生活上の小さな違和感を**写真＋コメント**で投稿
   - 写真はローカルファイルのドラッグ＆ドロップまたはサンプルプリセットからワンタップ選択可能
   - 投稿された気づきはそれぞれスレッド（カード／リスト）として一覧表示

2. **ステップ2：視点の転換**
   - 気づきに対して、メンバーからのコメント・感想・多角的な視点を時系列で共有
   - 思考を拡張する「視点ヒント」（「もし別の用途なら？」「時間をずらすと？」「子ども・シニア目線なら？」「逆転させると？」「他業界のアナロジー」）をワンタップ挿入可能
   - 投稿者が**「意見収集の終了を宣言する」**ボタンを押すと、自動的にステップ3（ブラッシュアップ）へ移行

3. **ステップ3：アイデアブラッシュアップ**
   - メンバー同士のチャットディスカッション
   - **AIからのリアルタイムフィードバック・壁打ち**
     - SCAMPER発想法（代用・結合・適応・逆転など）
     - ターゲット視点のシフト
     - 別業界アナロジー
     - 持続可能性・マネタイズ設計
     - キャッチコピー＆ネーミング提案
   - 完成したら**「アイデアバンクにストックする！」**ボタンで保存

## 🌟 補足機能・仕様への完全対応

- **メンバー選択機能**
  - アプリ起動時にメンバー選択画面（`Ricky`, `h-a-r-u`, `tatsu`, `千股弘旗`）が並び、選択したメンバーとしてログイン・操作
  - 画面上部のアバターボタンからいつでも切り替え可能
- **いいね＆確認済み機能**
  - 各ステップの投稿・コメント・チャットに「いいね」ボタンを配置
  - **誰が確認・いいねしたか（アバターアイコンおよび名前一覧）が一目でわかるUI**
- **トップ画面のデータ出力機能**
  - ヘッダーの「データ出力」ボタンから全投稿テキストを一括ダウンロード可能
  - テキスト形式 (`.txt`)、Excel対応CSV形式 (`.csv`)、構造化JSON形式 (`.json`) の3形式に対応
- **テキストマイニング分析ダッシュボード**
  - ヘッダーの「テキストマイニング」ボタンから起動
  - **インタラクティブ・ワードクラウド (Canvas描画)**: 頻出度に応じた文字サイズとカラー表示
  - **頻出キーワード順位**: 出現回数バーチャート
  - **共起ネットワーク**: 同時出現する単語同士のつながり（関連性）
  - **メンバー活動分析**: 誰がどの活動を活発に行っているかの統計
